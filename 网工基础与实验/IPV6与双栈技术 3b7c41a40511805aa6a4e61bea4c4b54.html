IPv4 与 IPv6 基础笔记

一、IPv4

1. 基本信息

  • 地址长度：32 位
  • 分组方式：分为 4 组，每组 8 位
  • 字节数：4 字节
  • 表示方式：点分十进制
  • 示例：192.168.1.1

IPv4 地址总数：

即约 43 亿个地址。实际可供设备使用的地址数量更少，因为部分地址具有特殊用途。

2. 地址结构

IPv4 地址由两部分组成：

  • 网络部分：标识设备所在的网络
  • 主机部分：标识该网络中的具体设备

子网掩码或前缀长度用于区分网络部分与主机部分。

示例：

  • IPv4 地址：192.168.1.10/24
  • 网络部分：192.168.1.0
  • 主机部分：最后 8 位

3. 传统分类

IPv4 地址传统上分为 A、B、C、D、E 五类：

类别主要用途
A 类大型网络
B 类中型网络
C 类小型网络
D 类组播
E 类实验和保留用途
现代网络主要采用 CIDR 和前缀长度进行地址划分，A、B、C 类属于传统分类方式。

4. 私有地址与公网地址

常见 IPv4 私有地址范围：

地址范围前缀
10.0.0.0～10.255.255.25510.0.0.0/8
172.16.0.0～172.31.255.255172.16.0.0/12
192.168.0.0～192.168.255.255192.168.0.0/16
  • 私有地址：供内部网络使用，不能直接在公网路由。
  • 公网地址：能够在互联网中进行全局路由。
  • NAT：可将私有地址转换为公网地址，缓解 IPv4 地址不足的问题。

5. IPv4 相关技术

  • 子网划分
  • NAT 地址转换
  • 静态路由
  • OSPFv2

二、IPv6

1. 基本信息

  • 地址长度：128 位
  • 分组方式：分为 8 组，每组 16 位
  • 每组字节数：2 字节
  • 总字节数：16 字节
  • 表示方式：冒分十六进制
  • 默认局域网前缀长度：通常为 /64

IPv6 地址总数：

约为：

IPv6 地址数量极其庞大，但仍需进行合理、分层的地址规划，便于路由汇总、网络管理和故障排查。

2. 十六进制与二进制的关系

一个十六进制数可表示 4 位二进制数：

因此：

一个完整的 IPv6 地址共包含 32 个十六进制数。

3. 地址结构

IPv6 地址通常由两部分组成：

  • 网络前缀：标识网络
  • 接口标识：标识网络接口，相当于 IPv4 中的主机部分

前缀长度的作用类似于 IPv4 的子网掩码。

示例：

  • IPv6 地址：2409:a00:7870:0:88e4::2219/64
  • 网络前缀：前 64 位
  • 接口标识：后 64 位

4. 全球单播地址

IPv6 全球单播地址的主要范围为：

2000::/3

其作用类似于 IPv4 公网地址，可在全球 IPv6 网络中进行路由。2001::/16 位于全球单播地址范围内，但不能代表全部 IPv6 公网地址。

5. 硬件与软件支持

使用 IPv6 需要相关硬件和软件共同支持：

  • 硬件：手机、电脑、服务器、路由器、交换机等
  • 软件：操作系统、应用软件和网络服务等

6. IPv6 相关技术

三、IPv6 地址简写规则

原始地址：

2409:0a00:7870:0000:88e4:0000:0000:2219

规则一：省略每组前导 0

每组开头连续出现的 0 可以省略，但一组中的所有数字不能直接全部删掉。

2409:a00:7870:0000:88e4:0000:0000:2219

规则二：全 0 的一组可写为 0

2409:a00:7870:0:88e4:0:0:2219

规则三：连续的全 0 组可用双冒号简写

连续两组或更多全 0 组可以使用 :: 代替：

2409:a00:7870:0:88e4::2219

一个 IPv6 地址中最多只能使用一次 ::，否则无法判断被省略了多少组全 0。

简写结果

2409:0a00:7870:0000:88e4:0000:0000:2219

可简写为：

2409:a00:7870:0:88e4::2219

IPV6双栈技术

现在公司内部使用IPV4 协议  ,想升级IPV6 网络 ，如何稳定切换到iPV6 

配置命令

AR1

sysname AR1

interface GigabitEthernet 0/0/0
 ip address 192.168.12.1 24
 quit

ip route-static 192.168.23.0 24 192.168.12.2
ip route-static 192.168.34.0 24 192.168.12.2

IPV6操作：
interface GigabitEthernet 0/0/0
 ipv6 enable
 ipv6 address 2001:12::1 64
 quit

ipv6 route-static 2001:23:: 64 2001:12::2
ipv6 route-static 2001:34:: 64 2001:12::2
