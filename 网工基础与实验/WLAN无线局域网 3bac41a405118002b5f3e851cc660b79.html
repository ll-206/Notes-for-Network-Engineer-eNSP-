WLAN无线局域网

WLAN 概述

WLAN（Wireless Local Area Network，无线局域网）是利用无线通信技术构建的局域网。现代企业网络通常采用有线与无线一体化的方式：有线网络负责骨干传输和设备互联，无线网络负责为终端提供灵活接入。

随着移动办公和无线终端数量增加，无线网络的重要性持续提升，但无线网络通常仍需要以有线网络作为承载基础。

基本网络组成

典型通信路径：

有线网络（网线、以太网协议）→ AP（无线访问点）→ 802.11 无线链路 → 无线终端

  • AP（Access Point，接入点）：连接有线网络与无线终端，向终端提供无线接入。
  • AC（Access Controller，无线接入控制器）：集中管理多个 FIT AP。
  • PoE 交换机：通过网线同时为 AP 传输数据和供电。
  • 无线终端：手机、笔记本电脑、平板等设备。

中大型网络的典型结构：

AC → PoE 交换机 → AP → 无线终端

PoE交换机就是能够用一根网线，同时给AP传输数据和提供电源的交换机。

AP 的工作模式

类型特点典型场景
FAT AP（胖 AP）具有独立配置和管理能力，可自行配置 SSID、密码、安全策略等家庭、小型办公室
FIT AP（瘦 AP）主要负责无线信号收发和终端接入，由 AC 统一配置、管理和监控机场、候车室、大型厂区、集团公司

FAT AP 不完全等于无线路由器。 无线路由器通常集成了路由器、交换机、AP、DHCP 和 NAT 等功能；FAT AP 主要强调 AP 能够独立配置和管理。家庭无线路由器中的无线功能通常以 FAT AP 方式工作。

AC 与 AP 的常见类型

AC 的设备形态

  • 盒式 AC：独立的无线控制器设备。
  • 板卡式 AC：以业务板卡形式安装在框式交换机等设备中。
  • 内置式 AC：部分交换机或网关集成 AC 功能。

AP 的部署环境

  • 室内 AP：用于家庭、办公室、教室、商场等室内场所。
  • 室外 AP：具有防水、防尘、耐高低温等能力，用于园区、广场、厂区等室外场所。

WLAN 组网方式

按 AC 的连接位置分类

组网方式说明特点
直连式组网AP 直接连接到 AC，AP 与 AC 之间不经过其他网络设备结构简单，适用于规模较小的网络，但 AC 接口和容量可能成为限制
旁挂式组网AC 旁挂在现有网络中，AP 通过交换网络与 AC 建立管理通道部署灵活，便于扩展，常用于中大型网络

简单来说就是旁挂式组网不用传输数据

按用户数据转发方式分类

转发方式用户数据路径特点
集中转发（隧道转发）AP 将用户数据通过 CAPWAP 数据隧道发送给 AC，再由 AC 转发便于集中控制和实施统一策略，但会占用 AC 的转发能力
本地转发（直接转发）用户数据由 AP 直接进入本地有线网络，不经过 AC减轻 AC 的转发压力，适合规模较大的网络

直连式/旁挂式描述的是 AC 在网络中的连接位置；集中转发/本地转发描述的是用户数据的转发路径。两组概念不能直接对应。

不同规模的应用场景

家庭和小型办公室

通常使用无线路由器或 FAT AP：

  • 向用户提供无线信号；
  • 配置无线网络名称（SSID）；
  • 配置无线密码和安全方式；
  • 管理员可以直接登录设备进行配置；
  • 无线路由器通常还承担路由、DHCP、NAT 等功能。

中大型场所

机场、候车室、大型厂区和集团公司通常采用 AC + FIT AP 架构：

  • FIT AP 负责无线信号收发和终端接入；
  • AC 对多个 AP 进行统一配置、监控和维护；
  • PoE 交换机为 AP 提供网络连接和供电；
  • 可统一管理 SSID、认证、安全策略、射频参数和漫游等功能。

Wi-Fi 与 LTE 的区别

技术网络类型接入方式典型用途
Wi-Fi无线局域网（WLAN）通过 AP 接入，通常使用 SSID 和密码或企业认证家庭、公司、校园、公共场所内部网络
LTE蜂窝移动通信网络通过运营商基站和 SIM 卡接入手机移动通信和广域无线接入

核心总结

  • WLAN 是通过无线方式提供局域网接入的技术，常见实现是 Wi-Fi。
  • AP 是无线终端接入有线网络的桥梁。
  • FAT AP 可以独立管理，适合小型网络。
  • FIT AP 通常由 AC 统一管理，适合中大型网络。
  • PoE 交换机可以通过一根网线同时为 AP 供电和传输数据。
  • AC 的连接位置分为直连式和旁挂式；用户数据转发方式分为集中转发和本地转发。
  • Wi-Fi 属于无线局域网技术，LTE 属于蜂窝移动通信技术。

需求二：AP 自动向 AC 进行注册

指的是 FIT AP 启动后主动寻找 AC，并与 AC 建立管理连接，使 AC 可以统一管理 AP 的过程。

思路上：

1）要进行注册，AP要知道AC是谁。

常用方法，DHCP_option

2）AP和AC要路由互通（基础配置已经完成了这一步）

3）AC要给AP进行配置信息

通过DHCP_OPTION 43获取AC的IP地址信息

[DHCP-ip-pool-200]option 43 ?
  ascii       The DHCP option's type is a ASCII string
  hex         The DHCP option's type is a hex string
  ip-address  The DHCP option's type is IP address 
  sub-option  Configure the DHCP sub-options
[DHCP-ip-pool-200]option 43 sub-option 3 ?
  ascii       The DHCP option's type is a ASCII string
  hex         The DHCP option's type is a hex string
  ip-address  The DHCP option's type is IP address
  
  Option 43 本身只是一个扩展字段，里面存放的数据可以有不同表现形式
  ascii  按照 ASCII 字符串发送
  hex  使用十六进制格式
  ip-address  存放一个IP地址类型的数据
  sub-option  在Option 43里面继续划分子字段

华为规定：

Option 43 的 sub-option 3 用来存放 AC 地址，而地址可以使用 ASCII 字符串形式保存

# 配置CAPWAP源接口
指定 AC 控制器 通过哪个接口使用CAPWAP隧道协议管理AP
capwap source interface Vlanif 220


# 配置默认路由
ip route-static 0.0.0.0 0 192.168.220.254

capwap source interface Vlanif 220指定 AC 建立 CAPWAP 隧道时使用的源接口，即指定 AC 与 AP 通信的 IP 地址。

CAPWAP（Control And Provisioning of Wireless Access Points）是一种用于 AC 和 AP 之间通信的协议。
作用：

1. 控制隧道（Control Tunnel）

用于 AC 管理 AP。

传输：

  • AP 注册信息
  • AP 配置下发
  • SSID配置
  • 射频参数
  • 用户认证信息
  • AP状态检测

例如：

AC配置：

SSID: company
密码: 12345678

通过 CAPWAP 控制隧道下发给 AP。

2. 数据隧道（Data Tunnel）

用于传输无线用户的数据。

例如：

用户访问服务器：

手机
 |
WiFi
 |
AP
 |
CAPWAP数据隧道
 |
AC
 |
服务器

用户数据经过 CAPWAP 隧道传到 AC，再转发出去。
