二层端口隔离

1. 概念

端口隔离（Port Isolation）是一种二层安全技术，用于限制同一交换机上指定端口之间的二层通信。

主要作用：

  • 防止同一 VLAN 内的用户互相访问
  • 提高接入网络的安全性
  • 在正确规划隔离关系的前提下，保留用户访问网关、服务器和 Internet 的能力

简单理解：VLAN 主要隔离不同 VLAN 的广播域；端口隔离主要限制同一 VLAN 内指定端口之间的通信。

2. 为什么需要端口隔离

在普通交换网络中，如果 PC1、PC2、PC3 都属于 VLAN 10，它们通常可以直接进行二层通信。

VLAN 10：192.168.10.0/24

PC1 ↔ PC2
PC1 ↔ PC3
PC2 ↔ PC3

但在酒店 WiFi、宿舍网络、企业访客网络和公共无线网络中，通常需要实现：

用户 A × 用户 B
用户 A × 用户 C
用户 B × 用户 C

用户 → 网关 → Internet   √

此时可以使用端口隔离，限制用户端口之间的二层转发。

3. 工作原理

3.1 未开启端口隔离

交换机根据 MAC 地址表进行二层转发。

PC1
 │
GE0/0/1
 │
交换机
 │
GE0/0/2
 │
PC2

当 PC1 向 PC2 发送数据时：

  1. 交换机学习 PC1 的源 MAC 地址。
  1. 交换机查询目标 MAC 地址对应的出接口。
  1. 交换机从 PC2 所在端口转发数据帧。

结果：PC1 可以直接访问 PC2。

3.2 开启端口隔离

交换机将指定用户端口加入隔离范围。

PC1 ── GE0/0/1 ┐
                ├── 交换机（隔离）
PC2 ── GE0/0/2 ┘

当 PC1 访问 PC2 时：

  1. 数据帧进入交换机。
  1. 交换机发现入接口和目标出接口之间存在隔离关系。
  1. 交换机不再向目标用户端口转发该数据帧。

结果：PC1 与 PC2 无法直接进行二层通信。

4. 端口隔离的特点

4.1 在同一 VLAN 内实现隔离

例如：

VLAN 10

PC1：192.168.10.1/24
PC2：192.168.10.2/24

两台设备处于相同 VLAN 和相同网段，默认可以通信。将其连接端口设置为相互隔离后：

PC1 × PC2

4.2 不改变 VLAN 和 IP 地址规划

端口隔离只限制指定端口之间的转发关系：

  • 不需要为用户重新划分 VLAN
  • 不需要修改用户 IP 地址
  • 用户仍然属于原来的广播域

4.3 可以保留对网关和服务器的访问

典型设计中，用户端口相互隔离，但连接网关、服务器或上联设备的端口不加入相同的受限隔离关系，因此可以实现：

用户 A × 用户 B
用户 A → 网关       √
用户 A → 服务器     √
用户 A → Internet   √

“端口隔离不影响网关和服务器访问”并不是无条件成立。能否访问取决于设备的隔离模式、隔离组和端口角色配置。如果网关或服务器端口也被错误地设置为与用户端口相互隔离，相关访问同样会失败。

用户访问网关时，主机会把以太网帧发送给网关的 MAC 地址；交换机仍负责二层转发，网关收到后再执行三层路由。

5. 端口隔离与 VLAN 的区别

对比项VLAN端口隔离
作用层次二层二层
主要目的划分广播域限制用户端口之间的通信
隔离对象不同 VLAN通常是同一 VLAN 内的指定端口
是否改变网段通常需要不同网段不需要改变网段
对广播域的影响不同 VLAN 属于不同广播域通常不重新划分广播域，但会限制相关端口的报文转发
典型应用部门和业务网络划分访客、宿舍和公共接入用户隔离

6. VLAN 与端口隔离结合使用

企业访客 WLAN 示例：

      AC
       │
   VLAN 100
       │
    交换机
  ┌────┼────┐
 AP1  AP2  AP3
  │    │    │
用户A 用户B 用户C

所有访客用户使用相同的业务网络：

SSID：Guest
VLAN：100
地址：192.168.100.0/24

没有用户隔离时：

用户 A ↔ 用户 B

开启用户隔离后：

用户 A × 用户 B
用户 A → 网关 → Internet   √

7. WLAN 中的应用

无线网络中的以下功能采用了与端口隔离相似的思想：

  • 用户隔离（User Isolation）
  • STA 隔离（STA Isolation）
  • 同一 SSID 内终端隔离

7.1 企业访客 WiFi

要求：

  • 访客可以访问 Internet
  • 访客之间不能互相访问
  • 访客不能直接扫描或访问其他终端

7.2 公共场所 WiFi

常见场景：

  • 商场
  • 机场
  • 酒店
  • 校园公共区域

主要用于降低以下风险：

  • ARP 欺骗和 ARP 攻击
  • 文件共享暴露
  • 终端扫描
  • 用户之间的横向访问

交换机端口隔离主要面向有线物理端口；WLAN 中的 STA 隔离由 AP 或 AC 针对无线终端实施。二者目标相似，但具体实现位置和配置命令不同。

8. 总结

端口隔离是在不重新划分 VLAN 和 IP 网段的情况下，通过限制指定交换机端口之间的二层转发，实现同一 VLAN 内用户隔离的技术。

核心特点：

  • 属于二层安全技术
  • 主要限制同一 VLAN 内用户之间的直接通信
  • 不需要改变原有 IP 地址规划
  • 不重新划分 VLAN
  • 正确配置时可保留对网关、服务器和外部网络的访问
  • 常用于访客 WLAN、宿舍网络和公共接入网络

port default vlan 10
quit

interface GigabitEthernet 0/0/1

quit

三层端口隔离

1. 概念

三层端口隔离（Layer 3 Port Isolation）是一种三层网络安全隔离技术，用于限制不同三层接口之间的 IP 通信。

它解决的问题：

即使两个用户处于不同 VLAN、不同网段，通过三层路由也能互相访问的问题。

简单理解：

  • 二层端口隔离：阻止同一个 VLAN 内用户互访。
  • 三层端口隔离：阻止不同 VLAN、不同网段之间通过三层转发互访。

配置命令

sysname SW1

vlan batch 10 20 30

interface GigabitEthernet 0/0/1
port link-type access
port default vlan 10
quit

interface GigabitEthernet 0/0/2
port link-type access
port default vlan 20
quit

interface GigabitEthernet 0/0/3
port link-type access
port default vlan 30
quit

interface Vlanif 10
ip address 192.168.10.254 24
quit

interface Vlanif 20
ip address 192.168.20.254 24
quit

interface Vlanif 30
ip address 192.168.30.254 24
quit

port-isolate mode all

interface GigabitEthernet 0/0/1
port-isolate enable group 1
quit

interface GigabitEthernet 0/0/2
port-isolate enable group 1
quit

MUX-vlan

MUX-VLAN（Multiplex VLAN，多路复用 VLAN）是一种二层 VLAN 隔离技术。
在同一个 VLAN 广播域内，实现用户之间的隔离，同时允许用户访问公共资源。

注意这个是二层VLAN技术，当IP网段不一样时是无法使用的。（vlan标签和网段并没有什么关联，只不过为了方便才让两者一致）

所有设备都能互访的为主VLAN 其余为从VLAN

组间可以通信的是团体组，组间不能通信的是隔离组

团体组内部可以互通，和主vlan可以互通，不能和隔离组互通
隔离组内部不可以互通，和主vlan可以互通，不能和团体vlan互通

配置命令：

SW1

[SW1]sysname SW1

vlan batch 10 20 30

port-group group-member GigabitEthernet 0/0/1 GigabitEthernet 0/0/2
port link-type access
port default vlan 10
quit

port-group group-member GigabitEthernet 0/0/3 GigabitEthernet 0/0/4
port link-type access
port default vlan 20
quit

interface GigabitEthernet 0/0/5
port link-type access
port default vlan 30
quit

vlan 30
mux-vlan
subordinate group 10  //
subordinate separate 20
quit

port-group group-member GigabitEthernet 0/0/1 to GigabitEthernet 0/0/5
port mux-vlan enable
quit
团体组内部可以互迪,和主vlan可以互通,不能和隔离组互通
隔离组内部不可以互通,和主vlan可以互通,不能和团体vlan互通
团体组和隔离组之间都不能通信

团体组可以创建多个;隔离组只能创建一个

MQC

QoS（Quality of Service，服务质量）

QoS是一种网络流量控制和管理技术，用于在网络资源有限或发生拥塞时，根据不同业务的重要程度，对数据流进行分类、优先级划分、带宽分配、延迟控制和丢包管理，从而保证关键业务（如语音、视频会议）的通信质量。

简单来说：

QoS就是通过对不同类型的数据提供不同等级的服务，保证重要业务优先传输。

MQC（Modular QoS Command-Line Interface，模块化QoS命令行接口）

MQC是华为设备实现QoS功能的一种模块化配置方式，通过将QoS配置拆分为三个独立部分：流分类（Traffic Classifier）、流行为（Traffic Behavior）、流策略（Traffic Policy），实现对不同业务流量的识别和控制。

简单来说：

MQC就是华为用来配置QoS的框架，通过“识别流量 → 定义处理动作 → 应用策略”的方式实现流量管理。

配置命令：

vlan batch 10 20 30

interface GigabitEthernet 0/0/1
 port link-type access
 port default vlan 10
 quit

interface GigabitEthernet 0/0/2
 port link-type access
 port default vlan 20
 quit

interface GigabitEthernet 0/0/3
 port link-type access
 port default vlan 30
 quit

interface Vlanif 10
 ip address 192.168.10.254 24
 quit

interface Vlanif 20
 ip address 192.168.20.254 24
 quit

interface Vlanif 30
 ip address 192.168.30.254 24
 quit


acl 3000
 rule permit ip source 192.168.10.1 0.0.0.0 destination 192.168.20.1 0.0.0.0
 quit


traffic classifier 4t5
 if-match acl 3000
 quit


traffic behavior 4t5
 deny
 quit


traffic policy 4t5
 classifier 4t5 behavior 4t5
 quit


interface GigabitEthernet 0/0/1
 traffic-policy 4t5 inbound
 quit

ACL里面的 permit表示“允许这条流量进入后续的流量策略匹配”。

另外，最好写上反向的ACL，在对应的接口绑定

rule permit ip source 192.168.20.1 0 destination 192.168.10.1 0

端口安全（Port Security）

端口安全是一种二层交换机安全技术，通过限制交换机接口上允许接入的 MAC 地址数量和类型，防止非法设备接入网络，提高网络访问控制能力。

简单理解：

端口安全就是把交换机端口和指定的 MAC 地址绑定，只允许合法设备通过该端口通信。

工作原理

普通交换机：

PC1 ---- G0/0/1 ---- SW

交换机会学习 PC1 的 MAC 地址：

MAC地址表：
MAC1 → G0/0/1

如果攻击者拔掉 PC1，换上一台非法电脑：

非法PC ---- G0/0/1 ---- SW

交换机仍然会学习新的 MAC 地址，非法设备可以接入。

开启端口安全后：

G0/0/1 只允许 MAC1

如果出现其他 MAC：

MAC2 → G0/0/1

交换机会根据配置采取动作：

  • 丢弃报文
  • 报警
  • 关闭端口

功能介绍

enable —— 开启端口安全

port-security enable 开启当前接口的端口安全功能。

开启后，该接口才会开始：

  • 学习安全 MAC 地址
  • 限制 MAC 地址数量
  • 检查非法 MAC 地址

max-mac-num —— 限制最大 MAC 地址数量

port-security max-mac-num 数量port-security max-mac-num 数量

限制一个接口最多可以学习多少个 MAC 地址

原本改交换机限制了一个MAC地址，如果后面接入了一个新的终端，就会触发违规，新的终端无法通过该端口进行通信。

aging-time —— MAC 地址老化时间

[SW2-GigabitEthernet0/0/1]port-security aging-time ?
INTEGER<1-1440>  Aging time (in minute)

设置安全 MAC 地址多久没有通信后删除。

port-security mac-address sticky —— Sticky MAC绑定

开启 Sticky MAC（粘性MAC）学习功能，将接口动态学习到的 MAC 地址转换为安全 MAC 地址，实现 MAC 地址自动绑定。

实验：端口安全实操

配置命令：
SW2

sysname SW2

vlan 10

# 配置 G0/0/1 - G0/0/4 为 Access 接口并加入 VLAN 10
port-group group-member GigabitEthernet 0/0/1 to GigabitEthernet 0/0/4
port link-type access
port default vlan 10
quit

# 配置上联接口
interface GigabitEthernet 0/0/5
port link-type trunk
port trunk allow-pass vlan all
quit

# 开启端口安全
port-group group-member GigabitEthernet 0/0/1 to GigabitEthernet 0/0/4
port-security enable
quit

# 配置 G0/0/1 端口安全
interface GigabitEthernet 0/0/1
port-security enable
port-security max-mac-num 1
quit

port-security mac-address sticky

开启Sticky MAC学习功能，让端口之后学习到的动态MAC地址自动转换为Sticky安全MAC地址。

交换机重启之后还会记得。

验证：

把交换机重启reboot，用命令display mac-address security 查询就能看到sticky地址
